# Clínica Vida Mais

Sistema web simples desenvolvido em Java para gerenciamento de pacientes utilizando fila FIFO.

## Funcionalidades

- Cadastro de pacientes
- Organização por ordem de chegada
- Atendimento FIFO
- Exibição da fila
- Interface web local

## Estrutura utilizada

- Queue
- LinkedList
- FIFO (First In, First Out)

## Tecnologias

- Java
- HttpServer
- HTML/CSS

## Como executar

1. Execute o projeto
2. Acesse:

http://localhost:9090
